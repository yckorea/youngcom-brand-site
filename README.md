# 영컴통신 브랜드 홈페이지

영컴통신을 위한 반응형 한국어 원페이지 브랜드 사이트입니다. 순수 HTML, CSS, JavaScript만 사용했으며 별도 빌드 과정이 없습니다.

## 실행

`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

## 파일

- `index.html` — 사이트 콘텐츠와 구조
- `styles.css` — 디자인과 반응형 레이아웃
- `script.js` — 모바일 메뉴, 현재 섹션 표시, 스크롤 등장 효과

전화번호, 이메일, 사업자 정보, 상품명과 블로그 글은 교체하기 쉽도록 임시 문구로 작성되어 있습니다.
